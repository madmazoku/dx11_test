# Particle Simulation with Verlet Integration

Этот проект демонстрирует симуляцию частиц с использованием интеграции Верле в DirectX 11.

## Особенности

- **Интеграция Верле**: Более стабильная физическая симуляция по сравнению с интеграцией Эйлера
- **Compute Shader**: Параллельные вычисления на GPU для физики частиц
- **Geometry Shader**: Генерация сфер из точек в режиме реального времени  
- **Полный графический конвейер**: Vertex → Geometry → Pixel shader для рендеринга
- **Пружинные силы**: Взаимодействие частиц с пружинными силами
- **Гравитация**: Влияние гравитации на частицы
- **Ограничения**: Простые граничные условия (коробка)

## Архитектура

### Compute Shader (ComputeShader.hlsl)
- Использует интеграцию Верле: `newPos = 2*pos - oldPos + acceleration*dt²`
- Вычисляет силы между частицами (пружинные силы)
- Применяет гравитацию и демпфирование
- Работает с 64 потоками в группе для эффективности

### Шейдеры рендеринга
- **Vertex Shader**: Трансформирует позиции частиц в пространство экрана
- **Geometry Shader**: Генерирует сферы из точек (20 треугольников на сферу)
- **Pixel Shader**: Освещение с учетом скорости для визуализации

### Структура данных
```cpp
struct Point {
    float3 position;     // Текущая позиция
    float3 oldPosition;  // Предыдущая позиция (для Верле)  
    float3 acceleration; // Ускорение
};
```

## Компиляция

1. Компилируйте шейдеры:
```bash
compile_shaders.bat
```

2. Компилируйте C++ код в Visual Studio с проектом dx11_test.vcxproj

## Использование

- Запустите исполняемый файл
- Окно покажет анимированные сферы, представляющие частицы
- Нажмите Escape для выхода
- Симуляция работает ~60 кадров в секунду

## Параметры симуляции

В `ComputeShader.hlsl`:
- `k = 0.5f` - жесткость пружины
- `r0 = 0.3f` - равновесная длина пружины  
- `dt = 0.016f` - временной шаг (~60 FPS)
- `damping = 0.98f` - коэффициент демпфирования
- `gravity` - вектор гравитации

## Преимущества интеграции Верле

1. **Стабильность**: Лучше сохраняет энергию системы
2. **Простота**: Не требует явного хранения скорости
3. **Точность**: Более точная для консервативных сил
4. **Производительность**: Меньше вычислений на частицу
